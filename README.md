## 🚀 Tecnologias

Esse projeto foi desenvolvido com as seguintes tecnologias:

- Angular
- Typescript

## 💻 Projeto

Um simples gerador de CPF, com tela de autenticação simples, para pratica e testes de desenvolvimento
Todos os CPF's gerados, são fictícios e utilizados para teste. Nenhum dado real é gerado e trafegado.

- [visite o projeto online](https://gerador-cpf-sigma.vercel.app/login)
